# Project Overview

**Project:** Royal Paparazzi Website

**Target Business:** Royal Paparazzi

**Project Type:** Business Website

**Status:** In Development

**Developers:** Chinedu + Andrew

**Started:** August 25, 2026

## Goal

Create a professional online presence for Royal Paparazzi.

## Current Objective

Build and deploy a professional website concept that can be presented to Royal Paparazzi as a potential website solution.

## Project Context

Royal Paparazzi is a photography/events business that currently does not have an official website. Its existing online presence primarily consists of promotional posters and social media.

This project is being developed proactively as a potential client acquisition opportunity. Royal Paparazzi has not yet been engaged as a client.

## Current Scope

The project is currently focused on a professional business website built using HTML, Tailwind CSS, and JavaScript.

The initial website will provide a professional presentation of the business, its services, photography work, and contact information.
